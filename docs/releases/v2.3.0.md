# Release Notes — v2.3.0

All changes since `v2.2.0` (2026-07-02).

## Added

### New package: `drawio-mcp-claude-plugin` (v0.1.0)

Claude Code plugin packaging the Draw.io MCP server for the Claude Code plugin ecosystem:

- Plugin manifest at `packages/drawio-mcp-claude-plugin/.claude-plugin/plugin.json` — registers the `drawio` MCP server (`npx -y drawio-mcp-server --editor`).
- Marketplace manifest at `.claude-plugin/marketplace.json` — install with `/plugin marketplace add lgazo/drawio-mcp-server`, then `/plugin install drawio`.
- Slash commands `/drawio-open <file-or-url>` (import XML/SVG/PNG file or URL and open the editor) and `/drawio-status` (health check + connected documents).
- Jest suite validating the plugin manifest schema and command frontmatter.
- Dedicated CI workflow: `.github/workflows/claude-plugin-ci.yml` (audit, lint, tests on plugin + marketplace paths).

### New `install` subcommand in `drawio-mcp-server`

Configure MCP hosts from the CLI: `npx drawio-mcp-server install <host>` — supported hosts: `claude-code`, `claude-desktop`, `codex`, `zed`, `opencode`, plus `all`.

- Per-host adapters:
  - `codex` — `~/.codex/config.toml`, TOML round-trip via `smol-toml`; env rendered as an inline table to prevent orphan `[env]` blocks.
  - `zed` — `settings.json` `context_servers`.
  - `opencode` — project `./opencode.json` first, else `~/.config/opencode/opencode.json`.
  - `claude-desktop` — per-OS config paths, JSONC merge.
  - `claude-code` — `~/.claude.json` merge.
  - `all` — fan out to every known host at once, with per-host path overrides.
- Per-host `--config-path=host=path` overrides when using `all`.
- Shared `config-io` helpers with format-preserving parsers (`jsonc-parser` for JSON, block-splicing TOML merger).
- Safety: atomic writes (temp file + `fs.rename`), `.bak-<epoch>` backup on first write, refusal to overwrite a differing entry without `--yes`.
- Flags: `--name`, `--editor`/`--no-editor`, `--http-port`, `--extra-arg`, `--env`, `--config-path`, `--print`, `--dry-run`, `--uninstall`, `--yes`.
- Unit + integration tests; integration tests sandbox `spawnSync` so they never touch real host configs.

### New MCP tools

- `set-document-title` — set the title of the active document.
- `save-document` — save the active document.
- Both registered in the server and plugin tool registries; `TOOLS.md` updated.

## Fixed

- **Import-diagram replace page state** — `editor.setGraphXml` swaps `graph.model.root` wholesale but left `ui.currentPage.{root,viewState,graphModelNode}` pointing at pre-import state, which could blank the canvas and risk a stale serialization on save. `sync_live_current_page_state` now runs after the replace and new-page branches; covered by a real-environment regression test asserting the imported cell survives a page round-trip and file serialization.
- **Docker build** — the Dockerfile predated the `drawio-mcp-compat` / `drawio-mcp-dev-proxy` package split. The build now copies all workspace packages and builds compat → dev-proxy → plugin → server, mirroring the CI order.
- **CI** —
  - Node versions aligned across workflows (extension CI matrix `[22.x, 24.x]`, package/publish on `24.x`; replaces EOL `23.x`) and step names normalized.
  - `extension-package.yml` now reads the extension's own version, fixing artifact-path mismatches that made uploads fail.
  - Package/publish flows build `drawio-mcp-compat` before the plugin.
  - Audit-flagged dependency bumps (`pnpm audit` findings resolved, obsolete audit overrides dropped).
- **Codex install** — env vars rendered as a TOML inline table so the generated config does not gain an orphan `[env]` table.
